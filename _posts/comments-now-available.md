Small but nice update: you can now leave comments on blog posts.

Scroll to the bottom of any post and you will find a comment section powered by
**Giscus**. It uses GitHub Discussions as the backing store, which means a
couple of things:

- **To comment, you need a GitHub account.** If you have one, great &mdash; sign
  in and post away. If you do not, signing up is free and takes about a minute.
- **No tracking, no ads, no third-party databases.** Your comment lives in the
  website's Discussions section, fully visible and under your control.
- **You get notified of replies** through GitHub, the same as any discussion
  thread.

The system maps each post to a discussion thread automatically, so comments stay
organised per article. First-time commenters on a given post will trigger the
creation of a fresh thread &mdash; after that, it is just a conversation.

If you have spotted a typo, want to disagree with something I wrote, or just
feel like saying hello &mdash; go ahead. The comment box is waiting at the
bottom of this very page.

> Forum is also available at [/forum](/forum) &mdash; it redirects to the
> project's Discussions hub, where you can start broader topics.
